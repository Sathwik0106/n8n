# SATHWIK ARCHITECTURE STUDIO — Works, Tectonics & Spatial Form

Official portfolio and monograph website of **Ar. Sathwik Reddy** (AA Dip, M.Arch, FIIA, COA Registered Architect).

An award-winning architectural practice specializing in sculptural residences, contemplative pavilions, and climatic vernacular modernism.

---

## 1. Project Overview & Features

Built with **React 19, TypeScript, Vite, and Tailwind CSS v4**, this website presents an authentic, high-end editorial experience showcasing architectural works:

* **Editorial Hero Canvas**:
  * Typography featuring Cormorant Garamond & Plus Jakarta Sans.
  * Geographical coordinates (`17.3850° N, 78.4867° E`), firm manifesto, and metrics strip (14+ Years, 38 Built Works, AD100 Atelier, 11 Awards).
  * Direct featured project monograph preview (*The Monolith Residence*).

* **Interactive Works Gallery**:
  * Filterable by typology: *All Works*, *Residential*, *Cultural*, *Commercial*, *Hospitality*, *Interior*.
  * View Modes:
    * **Finished Photography View**: High-resolution architectural photography.
    * **Technical Drawings & Blueprints Mode**: Flips cards to display technical architectural floor plans, axonometric drawings, and schematic sections with scale.
    * **Grid View vs Architectural Index List View**.

* **Comprehensive Case Study Drawer (Monograph Modal)**:
  * Full-resolution photo gallery with thumbnail switcher.
  * Architectural narrative, design brief, and climatic strategy.
  * Materiality & Tectonics breakdown (e.g., Board-marked concrete, Corten steel, Travertine marble, Teakwood louvers).
  * Ecological sustainability metrics & Award credentials.
  * Complete technical data ledger (Client, Location, Structural System, MEP, Area).

* **Architectural Manifesto (Philosophy)**:
  * 4 Tectonic Principles: Topography & Climate Geometry, Tectonic Material Honesty, The Poetics of Shadow & Light, and Vernacular Modernism.
  * Signed reflection from Principal Architect Ar. Sathwik Reddy.

* **The Atelier & Principal Profile**:
  * Academic pedigree (Architectural Association London / CEPT) & Council of Architecture credentials.
  * Selected Press & Critical Publications (*AD100*, *Dezeen*, *ArchDaily*, *Domus*, *WAF Finalist*).

* **Bespoke Project Commissioning Form**:
  * Interactive project brief submission (Typology, Target Area, Budget Scope, Timeline, Vision).
  * Generates an official **Atelier Project Commission Dossier** (`#ATL-2024-XXXX`).
  * Physical Atelier locations in Jubilee Hills (Hyderabad) and Indiranagar (Bengaluru).

## 2. Quickstart

To run the portfolio locally:

```bash
cd frontend
npm run dev
```

Visit: `http://localhost:5173`

To build the static distribution bundle:

```bash
cd frontend
npm run build
```
Output files will be generated in `frontend/dist/`.
